# 易换校园

让闲置遇见需要。面向校园的二手商品发布、搜索、收藏与交易助手原型。

**当前状态：网站和规则演示可运行；应用大模型 API 尚未配置，真实 AI 模型联调待完成，尚不能宣称参赛硬性门槛已全部满足。**

核心后端在用户电脑的码道 CodeArts Agent 内实际生成；Codex 辅助完成中文界面、联调修复、正式测试和交付文档。开发截图在 `开发证据/`。不要将辅助材料冒充码道开发记录，也不要将模拟模型测试冒充真实模型接入。

## 现在怎么打开

当前这台电脑已安装依赖并构建，若服务正在运行，浏览器打开：

http://localhost:3000

以后重新开机：双击本文件旁的 **启动平台.cmd**，等待控制台显示“易换校园后端已启动”，再打开上述网址。使用期间保留这个黑色窗口；关闭窗口会停止服务。如果端口已占用，先使用已运行的页面，或只停止本项目此前启动的窗口。

这只在自己电脑上运行。`localhost` 不可作为其他电脑访问的网址，也不能当作已上线的证明。

## 在其他电脑首次运行

1. 安装 Node.js 24 或更新的兼容版本，安装后重开终端。
2. 将项目解压到普通文件夹，避免放在客户端安装文件夹内。
3. 双击 `启动平台.cmd`；首次会安装依赖，需要网络。
4. 访问 http://localhost:3000。

也可以在本目录终端输入：

```powershell
npm.cmd run install:all
npm.cmd run build
npm.cmd start
```

开发模式：`npm.cmd run dev`，浏览器访问终端显示的 Vite 地址（通常 http://localhost:5173）。SQLite 与 `.env` 路径固定在项目目录，不随启动终端位置变化。

## 接通真实大模型：参赛前必须补齐

码道中的开发额度与网站运行时的 API 是不同用途。不要尝试提取或复用码道客户端内部令牌。

先向比赛群或指导教师确认是否提供：应用可调用的模型服务地址、API Key、模型 ID，以及是否支持 Chat Completions 的 `tools` 工具调用。如果未提供，可使用自己获准使用的兼容模型服务；是否收费和额度以服务商当前控制台为准。

1. 将根目录的 `.env.example` **复制**为 `.env`。Windows 资源管理器打开“查看 → 显示 → 文件扩展名”，避免误命名为 `.env.txt`。
2. 用码道打开 `.env`，在本机填写以下三项，不要把真实密钥发到聊天、录屏、截图或 Git：

```dotenv
AI_BASE_URL=服务商提供的接口基础地址，通常以/v1结束
AI_API_KEY=仅在自己电脑上填写真实密钥
AI_MODEL=服务商提供且支持tools的模型ID
```

这里没有默认服务商，没有自动购买。`AI_BASE_URL` 应为包含 API 版本的基础地址；不要填写 `/chat/completions` 的完整地址，程序会追加这段路径。也不要原样保留示例中文。

3. 停止本项目服务后重新运行 `启动平台.cmd`。页面助手顶部应显示“已配置模型接口”。这只代表配置齐全，**不代表真实调用已经成功**。
4. 输入“查找30元以内的教材”，确认回复成功、工具记录包含 `search_products`、商品卡片可打开。继续追问，并录下真实过程。接口失败会明确报错，不会悄悄切成离线成功结果。
5. 若 HTTP 401/403，检查密钥和权限；429 检查额度和限流；404 检查基础地址与模型 ID；模型不返回工具调用时换支持 tools 的模型，并检查接口文档。

模型返回的是建议；价格工具参考本平台在售标价，不能当作全网成交价或鉴定报告。风险工具不能保证交易安全。

## 数据保存与配置

- 商品、账号、会话：`server/data/yihuan.db`，重启不会自动清空。
- 上传图片：`server/uploads/`，只接收 JPG/PNG/WebP，最多 3MB，采用随机文件名。
- 运行日志：`server/logs/`；不要把含个人信息的日志公开。
- 数据目录可通过 `DATA_DIR`、`UPLOADS_DIR`、`LOGS_DIR` 环境变量覆盖。
- `.env`、数据库、上传图片、日志和开发环境缓存不入 Git。

备份时先停止本项目，再一起备份数据库与上传目录；不要单独拷贝仍有写入的 SQLite 主文件。

## 部署与提交
